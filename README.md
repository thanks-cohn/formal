# Formal

**Formal and Correct Paths of Documentation**

A professional archive for preserving letters, complaints, and other records in a clear, formal, and correctly structured path of documentation.

The site keeps each document in a consistent reading format: **section title, title, subheader, and body**, with previous/next navigation and a vertical document rack for moving through the collection.

The site is intentionally static so it can be deployed cleanly on GitHub Pages or Cloudflare Pages without changing its visual behavior or interaction model.
